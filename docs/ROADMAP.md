## Definition of useful
BlackIndex is successful when an operational question can be asked in plain language and the system returns:
1. relevant primary-source evidence,
2. what is established vs inferred,
3. reusable patterns,
4. existing controls/detections,
5. implementation gaps,
6. direct provenance back to the source.
